Portafolio de evidencias
Objetivo:
El objetivo de este portafolio es recopilar las evidencias de aprendizaje desarrolladas a lo largo del
curso. A través de este conjunto de prácticas, se busca demostrar el dominio de los pilares de la
Programación Orientada a Objetos (POO), el diseño de interfaces gráficas de usuario (GUI), la 
persistencia de datos mediante archivos y bases de datos relacionales, reflejando el progreso de nuestro
conocimiento a través de las evaluaciones.

Elementos aprendidos:
A lo largo de la materia, aprendi a como hacer que los programas reciban la información que escribe
el usuario y la procesen correctamente, el uso de clases y herencia para ordenar el código
lo que nos ayuda mucho ya que no uso código basura y a usar las interfaces graficas
